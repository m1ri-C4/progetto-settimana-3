# progetto-settimana-3

L'idea del progetto settimanale:
è una pagina web che permette di raccogliere e organizzare le proprie ricette. 
All'interno della pagina troviamo varie funzionalità studiate in quest'ultima settimana.
Ad esempio i vari bottoni con funzionalità aggiungi, elimina, viualizza; o anche il form con i messaggi di errore.
Abbiamo anche il contatore che si aggiorna rispetto le ricette presenti, aggiunte, fatte e preferite, con una barra dinamica delle cose fatte.
Un filtro per ricette preferite, fatte e totali.
Novità è il bottone darkMode.
